Quick Add

Jobinja only

Paste a public Jobinja job URL, a Jobinja search-results URL, or type a Persian/English search phrase. JobHunter detects the input type and uses the same bounded acquisition pipeline as the normal market sync.

What Quick Add accepts

One Jobinja job URL: adds that exact opportunity to the local catalog, preserves its detail-page evidence, parses it, and optionally translates it.

One Jobinja /jobs search URL: preserves the filters already encoded by Jobinja, discovers matches, and optionally fetches a bounded detail sample.

One Persian or English phrase: builds a normal Jobinja keyword search for that phrase. This is useful for a role or technology that is not yet in your saved search catalog.

Other websites are rejected here because the current approved source adapter is Jobinja.
