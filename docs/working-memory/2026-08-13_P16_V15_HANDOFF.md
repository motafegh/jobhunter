## v15 correction

Contract:

```text
job-analysis-english-v15 / job-analysis-v4
```

v15 preserves all successful v14 mechanics and changes only the remaining boundaries:

```text
residual coverage obligation
!=
employer requirement strength
```

Residual coverage now carries `obligation_hint = null`. Every residual must still be extracted or
explicitly excluded, but required/preferred/contextual is derived from exact source wording.

v15 also defines the concept-type ontology explicitly:

- `skill`: ability/proficiency to perform a task/activity;
- `tool`: named technology/instrument;
- `knowledge`: subject-matter understanding;
- `practice`: method/discipline;
- `domain`: industry/problem area;
- `experience`: prior applied exposure;
- `education`: credential;
- `other`: candidate traits, values, behavioral expectations, or professional qualities that do
  not fit the capability categories above.

The concept-type decision remains semantic/model-owned and human-reviewed. No vacancy-specific
`ethics`/`commitment` keyword patch was added.
