It uses the unchanged SHA-verifiable source anchor binding, source-qualified original items, exact original character/UTF-8 spans, a conservative alternative signal, existing B1 validation, and the existing B3 batch translator/B4v5 read-only candidate. The exact inputs/outputs are private; no labels were accepted. **Decision: reject automatic model-relabeled source categories for the prospective candidate**, rather than add a new prompt or model-to-accepted-fact layer. This is a narrow exposed probe, not a claim all model assistance is inferior.

## Source-first rubric and critical stop

Read each of the eight exact original employer descriptions once *before B2v3 candidate output*. Freeze an assistant-only source-first high-risk reference with exact original quote/source positions/UTF-8 hashes, categorical authority, qualification strength, alternatives/OR boundaries, duty evidence and unknowns; record incomplete denominator, prior reviewer experience, and absence of independent blind human certification. Never expose the original-source reviewer to model outputs first.

Predeclared evaluation must preserve:
- Source original SHA identity and quote anchoring, privacy and immutable app/corpus backups.
- Explicit assigned duties; no fabricated duties from applicant qualifications; do not mistake a goal/role description for an assigned daily action.
- Applicant requirements vs true advantages/optional or negative scope; do not convert work-implied capability into mandatory prior professional employment or all-of technology requirements.
- Explicit OR/AND and equivalence or specialty paths; a generic unresolved option scope cannot be scored as a verified complete Boolean graph.
- Source-described location, hours, compensation vs board-only metadata; preserve contradictory authority, nonclaims and unknowns.
- Semantic fidelity of negative/optional/years/technical term in every translation used as comparison evidence.
- Useful source-first partial results, uncertainty and withheld model claims rather than forcing more rigid micro-labels.

A heading-only quote used to establish a preference/section is **structural evidence**, not itself a missing qualification claim. A genuinely mixed sentence may span multiple correctly identified source items; mark its relation unresolved unless the source-owned meaning is fully preserved. Count tested independent assertions and unsupported/missing cases, not a fictional overall job-ad accuracy percentage.

**Hard stop:** any confirmed critical source-category misreading, an explicit duty omitted, unsupported required skill, wrong alternative OR/AND, material translation omission/strength reversal, ungrounded claim, source/accepted-artifact currentness drift, access challenge or budget exhaustion blocks the third B5 *promotion/acceptance* run. After any upstream failure, do not regenerate labels against those sources as another unseen B5: they become exposed. No B3/B4/v30 paired interpretation before source gate. Report source-first assistant status honestly rather than asserting independent blind review.

## Bounded downstream comparison if source gate passes

Use a separately reserved **80 physical translation HTTP attempts, 7,200 seconds max across sessions**, each local guarded session capped at 8 attempts/900 seconds and zero cross-cloud requests. Preserve incomplete/deferred/oversized item identity; never truncate and classify as a faithful translated fact. Native English is identity, not a fake translation. Translation-v2 named entity and critical technical terms require contextual original-only scrutiny. Treat all machine translations and model citations as unreviewed until evaluated.

The earlier B0 ceiling of up to **80 local paired analysis model requests** across the 6–8 third-cohort jobs remains **separate** from translation attempts, with the 6-hour B5 analysis cap, one primary design and at most one evidence-justified corrective approach. Compare the single frozen candidate against **unchanged English v30/v5 and original v9/v4**, using the same exact frozen source/translation dependencies and B4v5 usefulness/fail-soft semantics. Capture valid/pending/failed/abstained events, response/run IDs and observed elapsed/tokens, not fabricated scores. No accepted fact or new durable P1.6/Capability/Work/Market row.

**B5 pass** requires both source/translation integrity, no critical source/authority defects, and a same-source measured usefulness advantage (or clearly safer/less misleading results with useful retained evidence) against v30, plus intact historical acceptance and privacy/test/CI boundaries. A third failure is recorded as **B5 NOT ESTABLISHED, B6 STILL CLOSED**; do not enter an endless loop of exposed fixes/re-sampling or call a bounded engineering PASS a completed B5.
