The implemented contract identifiers are p16-e3-a2-semantic-v1 and p16-e3-candidate-envelope-v1. This slice is intentionally composition-based, not a new inherited production version. The system preserves meaning as supplied; it does not establish correctness from a cited handle. A wrong interpretation with an exact reference remains unreviewed; employer obligation is not established in any proposal view. Board-only interpretations are held for review without modifying their content. Relation/claim problems with identifiable dependencies withhold the affected scope; independent source and proposals remain. Empty or incomplete response never establishes absence. Even a structurally successful whole response remains qualified partial, pending cross-request planned-scope/delivery integration and semantic review. Source packet/response tampering and stale supplied binding are rejected by reconstruction; no current-store lookup or automatic reuse.
