# P1.6 B4v5 — source-qualified presentation and terminology reconciliation

**Date:** 2026-11-19
**Disposition:** PASS for exposed-cohort source-first presentation and provenance replay; full semantic/generalization NOT ESTABLISHED; no promotion.

## Why

The earlier B4v4c engineering milestone left three important source-meaning problems in its concise model output. The `tNhZ` original explicitly says financial/LLM familiarity is an advantage **but not mandatory**, yet model expectations omitted it. The `tMps` source permits **Middle OR Senior** experience tracks and a nested one-of-domain condition, while rejected model text suggested cumulative requirements. In `tNDx`, the ticketing system's original proper name **Fadak (original Persian proper name)** was mistranslated by B3 as **FDC**. The earlier B3 assistant semantic PASS missed this; its original audit record remains intact, but the finding must qualify any subsequent quality claim.

## What is implemented

- A new read-only B4v5 source-first projection over the exact four previously exposed B4v4c candidates. It does not overwrite B2/B3/v30/v9, call any model, create accepted employer facts or touch production SQLite.
- An “At a glance” section prioritizes optional/negative wording, source-qualified alternative eligibility tracks and explicit conditional acceptance statements. A detailed section retains each original-language quote, exact canonical source-item ID, B2 candidate strength/category and B3 English reading aid.
- Nested alternative eligibility graphs render as **OR/AND trees**. Middle/Senior and certificate-or-equivalent are not silently combined. Their original nested source spans remain exact and their independent English child target offsets stay **NOT ESTABLISHED**.
- An exact source-span-ID and target-SHA-bound reviewed B4v5 terminology overlay replaces **FDC** with **Fadak** in the presentation only. The earlier B3 translation remains immutable for audit. Two old generated model claims involving this corrected item are withheld.
- An original-source-only qualifications view remains available for `tMjm` without hallucinated duties. Existing model summaries are clearly marked as unapproved, not employer-authored or production-ready.
- A read-only replay verifier confirms all four source projections, exact item counts, both graph branches, the named-entity correction, code/input hashes, historical B4v4c verification and zero model calls or production promotions.
