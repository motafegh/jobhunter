### Board/source reconciliation repaired

The B1-compatible projection now maps all four observed discrepancy classes and preserves both source-owned values:

- \`tNhZ\`: employer LLM preference versus board skill strength; employer part-time/full-time arrangement versus board full-time mode.
- \`tMps\`: Middle/Senior source eligibility alternatives versus the board experience summary.
- \`tNDx\`: employer-description compensation versus structured board salary.

Salary discrepancy detection is intentionally narrow: it compares only explicit numeric amounts with the same stated currency and flags only non-overlapping values/ranges. Thus the EDR salary pair remains unresolved and preserved, while the Python/AI ad's 30-million lower bound overlapping its 30–50-million range is not mislabeled as a contradiction. Negotiable/non-numeric salary text is not guessed into a numeric conflict. No source is automatically selected as truth.

### Frozen semantic boundaries retained

- EDR teamwork remains preferred, not mandatory.
- Kaspersky specialist credentials and government/large-customer experience remain unresolved.
- Certificate OR equivalent knowledge remains a candidate alternative.
- Middle OR Senior and within-track AND / one-of-domain structures remain candidate-only.
- Part-time/full-time and remote are work arrangements, not applicant eligibility.
- Work-implied capability hints remain optional and do not create mandatory prior professional experience.
