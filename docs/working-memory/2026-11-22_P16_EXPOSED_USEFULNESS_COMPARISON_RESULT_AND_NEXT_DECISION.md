## 4. What the result supports—and what it does not

**Supported:** A bounded original-source-linked fallback can retain material work and applicant information when English v30 has no accepted output. It can highlight high-risk preferences, conditions and alternatives, preserve unknowns, retain exact source identity, and explicitly withhold earlier model claims affected by translation errors. This is a useful *design capability* on exposed cases.

**Not supported:** A proved improvement in user decision quality, faster reading, reliable generalized classification, complete employer fact coverage, translated nested branch fidelity, or accepted semantic output superiority over v30. The source-qualified 64-item presentation is relatively verbose and could require more effort than reading the original vacancy. Its “At a glance” shows counts and selected qualifications but not always a concise, trustworthy explanation of *what the job actually involves*. The source-role labels and OR paths remain candidates; a correct anchor proves location, not employer meaning.

**Risk:** Repeated deterministic source-category additions to B2v2–v5 improved retrospective matches after seeing four B5 cohorts but did not pass any prospective semantic source gate. Coding more heading variants can increase complexity while postponing the central product question: whether the user receives actionable, appropriately uncertain job understanding.

## 5. Next product/architecture decision

**Select a bounded, candidate-only decision-question-first B4v6 research slice on already exposed ads, not a fifth fresh B5 acquisition.** The target is a compact first view that answers role purpose, explicitly assigned work, required-versus-preferred capabilities, alternative eligibility, employment conditions and unknowns, with a click-through to exact original-source items and candidate English readings. Preserve distinct “work implies a useful capability” interpretation without fabricating mandatory prior paid experience or named tools.

Use deterministic SHA/DOM provenance, exact offsets, source identity, alternative-source *location*, currentness, and review-state bookkeeping. Keep ambiguous semantic category/strength/OR-AND interpretation candidate-only, with clear uncertainty or abstention. Optionally test **selective local-model reasoning** only for genuinely unresolved questions, with exact source references, a strict physical-call/time budget and a no-cloud policy. The previous three-case model-based relabeling performed worse on its exposed sample; it does not justify replacing all deterministic classifications with an LLM. Do not compensate by adding numerous rules to a single prompt.

**Acceptance for the next bounded slice:** predeclare a few distinct actionable questions, run a fair source-backed comparison between the existing verbose B4v5 view and a compact candidate; record unsupported mandatory claims, omitted explicit duties, incorrectly combined OR paths, unhelpful abstentions, token/time costs (if any), readability and user inspection steps. Prefer real owner or context-isolated reviewers for usefulness; if unavailable, retain the honest assistant-only limitation. Never label an exposed trial as unseen B5 or promote new facts to v30/v9/Capability/Work/Registry/Market.

A **later** B5 attempt requires a materially justified, frozen candidate, a distinct untouched source cohort, original-first review, separate translation and analysis model budgets, a measured same-source baseline comparison where evidence exists, and explicit fail/stop rules. B6 is still independently closed behind a rollback-verified promotion decision.
