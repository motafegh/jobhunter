# R05 A2 private local diagnostic usage

After checking out `agent/r05-diagnostic-safety-2026-09-24` and activating the project environment, list failed P1.6 attempts with `jobhunter --config config/local.toml diagnostics list --limit 20`. Inspect an attempt using `jobhunter --config config/local.toml diagnostics show <attempt-id>`. The default output contains attempt IDs, source-detail/version, model/prompt/schema identities, status, failure stage and optional partition index/total. It does not show model completion text or legacy untrusted error messages. Only if necessary in a private terminal, add `--include-response` to display the original available failed completion or normalized earlier partition fragment. Do not paste such output into issues, PRs, source files or the public corpus. `unavailable` means no completion was accessible; `oversize` means the response exceeded the per-capture limit; `model_validated_partition_structured` is a diagnostic fragment that may not have passed source-scope/global validation. A failed attempt never creates a pending analysis. Diagnostics are retained locally with bounded size/count and 14-day cleanup when the diagnostic store is accessed; backups and terminal output are not automatically erased.
